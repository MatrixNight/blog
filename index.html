Hello Vue3 学习笔记

现代化开发的概念

MPA（Multiple Page Application）：
多页面应用，即一个页面上可以有多个功能模块，每个模块对应一个页面，通过路由进行切换。

SPA（Single Page Application）：
单页面应用，即一个页面上只有一个功能模块，通过路由进行切换。

MPA的优点是可以实现模块化开发，可以按需加载，可以提高用户体验。
MPA的缺点：页面之间切换时，需要重新加载页面，导致用户体验不好。

SPA的优点是可以实现快速响应，可以节省服务器资源，可以提高用户体验。
它只有第一次访问的时候才需要经历一次完整的页面请求过程，之后的每个内部跳转或者数据更新操作，都是通过 AJAX 技术来获取需要呈现的内容并只更新指定的网页位置。
SPA 在页面跳转的时候，地址栏也会发生变化，主要有两种方式：

  • hash 模式：地址栏中会显示 # 号和 hash 值，如 http://www.example.com/#/about。
  • history 模式：地址栏中显示正常的 URL，如 http://www.example.com/about。

网页的 TKD 三要素是指一个网页的三个关键信息，含义如下：

  1. Title：网页的标题，即网页的网站的标题。
  2. Keyword：网页的关键词
  3. Description：网页的描述，是网页的简介，对搜索引擎的抓取和排序非常重要。

CSR（Client Side Rendering）

CSR（Client Side Rendering）即客户端渲染，即在浏览器端通过 JavaScript 动态生成网页内容，然后再将内容呈现给用户。

优点：

  • 首屏加载速度快，用户体验好。
  • 无需等待后端响应，可以实现即时交互。
  • 适合对 SEO 要求不高的场景。

SSR（Server Side Rendering）

SSR（Server Side Rendering）即服务端渲染，即在服务器端通过 Node.js 等技术生成网页内容，然后再将内容发送给浏览器，浏览器再将内容呈现给用户。

优点：

  • 首屏加载速度快，用户体验好。
  • 无需等待后端响应，可以实现即时交互。
  • 适合对 SEO 要求高的场景。

区别

CSR 与 SSR 的区别主要在于服务器端的渲染方式。

CSR 即客户端渲染，即在浏览器端通过 JavaScript 动态生成网页内容，然后再将内容呈现给用户。

SSR 即服务端渲染，即在服务器端通过 Node.js 等技术生成网页内容，然后再将内容发送给浏览器，浏览器再将内容呈现给用户。

CSR 适合对 SEO 要求不高的场景，如个人博客、新闻网站等。

SSR 适合对 SEO 要求高的场景，如电商网站、社交网站等。

Server-Side Rendering：服务端渲染，即在服务器端通过 Node.js 等技术生成网页内容，然后再将内容发送给浏览器，浏览器再将内容呈现给用户。

Client-Side Hydration：客户端激活，即在浏览器端激活 Vue 组件，使其与服务器端渲染的 HTML 内容同步。

Electron：使用 JavaScript、HTML 和 CSS 构建跨平台桌面应用程序。

Electron 是一个使用 Chromium 和 Node.js 构建的开源项目，它允许你使用 JavaScript、HTML 和 CSS 构建跨平台桌面应用程序。在构建时，Electron会把Node和Chromium一起打包为一个可执行文件，并将其打包为一个独立的应用。
